### 1. Riders

| **Method** | **Endpoint**  | **Request Body / Params**                           | **Description**                                            |
| ---------- | ------------- | --------------------------------------------------- | ---------------------------------------------------------- |
| **POST**   | `/api/riders` | Body: `{ "name": "...", "age": 25, "gender": "M" }` | Creates a new rider and calculates their base coefficient. |

---

### 2. Teams

| **Method** | **Endpoint**                             | **Request Body / Params**                                   | **Description**                                                                    |
| ---------- | ---------------------------------------- | ----------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| **POST**   | `/api/teams`                             | Body: `{ "name": "...", "ownerId": "uuid" }`                | Creates a new team, generates a blank tree, and sets the creator as admin.         |
| **DELETE** | `/api/teams/{teamId}`                    | Query: `?requesterId={uuid}`                                | Deletes the team (only if the requester is the admin).                             |
| **POST**   | `/api/teams/{teamId}/leave`              | Body: `{ "riderId": "uuid", "replacementAdminId": "uuid" }` | Allows a user to leave. If the user is the admin, they must provide a replacement. |
| **DELETE** | `/api/teams/{teamId}/members/{targetId}` | Query: `?adminId={uuid}`                                    | Kicks a member from the team. Only the admin can perform this.                     |
| **PUT**    | `/api/teams/{teamId}/admin`              | Query: `?currentAdminId={uuid}&newAdminId={uuid}`           | Hands over the admin role to another current member.                               |

---

### 3. Membership Requests

|**Method**|**Endpoint**|**Request Body / Params**|**Description**|
|---|---|---|---|
|**POST**|`/api/membership-requests`|Query: `?teamId={uuid}&riderId={uuid}`|Submits a request for a rider to join a team.|
|**GET**|`/api/membership-requests/team/{teamId}`|_None_|Gets all pending inbound requests for a specific team (for admins).|
|**GET**|`/api/membership-requests/rider/{riderId}`|_None_|Gets all pending outbound requests made by a specific rider.|
|**POST**|`/api/membership-requests/{requestId}/approve`|Query: `?adminId={uuid}`|Approves the request, adds the member, and recalculates the team coefficient.|
|**POST**|`/api/membership-requests/{requestId}/deny`|Query: `?adminId={uuid}`|Denies and deletes the request.|

---

### 4. Strava Integration

|**Method**|**Endpoint**|**Request Body / Params**|**Description**|
|---|---|---|---|
|**POST**|`/api/strava/connect/{riderId}`|Query: `?code={string}`|Swaps the Strava OAuth code for access/refresh tokens and saves them.|
|**POST**|`/api/strava/sync/{riderId}`|_None_|Fetches rides from the last 72h, evaluates achievements, and grants tree pieces. Returns `{"imported_rides": int}`.|

### 5. Statistics & Aggregations

|**Method**|**Endpoint**|**Request Body / Params**|**Description**|
|---|---|---|---|
|**GET**|`/api/stats/teams/{teamId}/points`|_None_|Returns the total points a team has accumulated.|
|**GET**|`/api/stats/teams/{teamId}/rides`|_None_|Returns a list of all rides (and points) contributed to this team.|
|**GET**|`/api/stats/teams/{teamId}/riders/{riderId}/points`|_None_|Returns total points contributed by a specific rider to a specific team.|
|**GET**|`/api/stats/riders/{riderId}/points`|_None_|Returns total points generated by a rider across _all_ their teams.|
|**GET**|`/api/stats/riders/{riderId}/totals`|_None_|Returns the rider's total lifetime distance and vertical gain.|

### 6. Leaderboards

|**Method**|**Endpoint**|**Request Body / Params**|**Description**|
|---|---|---|---|
|**GET**|`/api/leaderboard/teams`|_None_|Returns the global leaderboard of all teams sorted by total points.|
|**GET**|`/api/leaderboard/teams/{teamId}/riders`|_None_|Returns the intra-team leaderboard of riders sorted by contributed points.|

### 7. Trees & Decorative Pieces

| **Method** | **Endpoint**                                | **Request Body / Params**                            | **Description**                                                                          |
| ---------- | ------------------------------------------- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| **GET**    | `/api/trees/team/{teamId}`                  | _None_                                               | Returns the team's tree object (root, trunk, branch, leaf counts, and `isGrown` status). |
| **GET**    | `/api/trees/{treeId}/inventory`             | _None_                                               | Returns a list of `TreeOrnamentDto` objects that have not been placed on the tree yet.   |
| **GET**    | `/api/trees/{treeId}/pinned`                | _None_                                               | Returns a list of `TreeOrnamentDto` objects containing X/Y coordinates for rendering.    |
| **PUT**    | `/api/trees/ownerships/{ownershipId}/pin`   | Query: `?riderId={uuid}&posX={double}&posY={double}` | Places a decorative piece on the tree (requires `isGrown=true`).                         |
| **PUT**    | `/api/trees/ownerships/{ownershipId}/unpin` | Query: `?riderId={uuid}`                             | Removes a piece from the tree and puts it back in the team's inventory.                  |
